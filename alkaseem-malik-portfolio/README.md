# Alkaseem Malik — Developer Portfolio

Responsive developer portfolio adapted from the supplied layout, using original Alkaseem Malik resume content.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL shown by Vite.

## Build

```bash
npm run build
```

Deploy to Vercel with build command `npm run build` and output directory `dist`.

## Included

- Hero, About, Tech Stack, Experience, Education, Projects, Contact
- Dark/light toggle, mobile menu, project dialogs, email draft contact form
- Resume at `assets/Alkaseem_Malik_Resume.pdf`

No project repository links are fabricated. SiteSync AI live demo is linked.
